# 실시간 영상 번역 (Android)

폰에서 재생 중인 영상 소리를 듣고, 한국어 자막을 화면 위에 띄워 주는 앱입니다.
음성 인식(Vosk)과 번역(Google ML Kit) 모두 기기 안에서 무료·오프라인으로 동작합니다.
Android 10 이상이 필요합니다.

## APK 만들기
방법 A. Android Studio: 이 폴더를 열고 Run ▶ 또는 Build > Build APK(s)를 누릅니다.
방법 B. GitHub(설치 없이): 이 폴더를 GitHub 저장소에 올리면 Actions 탭에서 자동 빌드됩니다.
완료된 실행의 Artifacts에서 LiveTranslator-apk를 내려받아 폰에 설치하세요.
